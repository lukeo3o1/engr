$ engr-current work item --help   # cwd=r4/project
--- stdout ---
The steps of the current decomposition

Usage: engr-current work item [OPTIONS] <COMMAND>

Commands:
  add     Add a step
  revise  Reword a step
  state   Move a step's progress
  result  Record what a step produced. Omit --text to clear it
  commit  Point a step at a commit, as navigation rather than proof
  rm      Prune a step. Its id is not reused
  help    Print this message or the help of the given subcommand(s)

Options:
      --root <ROOT>  Workspace root. Defaults to the nearest ancestor containing .engr
  -h, --help         Print help
--- exit 0 ---
